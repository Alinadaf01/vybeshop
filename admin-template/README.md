# هُما — پنل مدیریت

داشبورد مدیریت فروشگاه با HTML، Tailwind CSS و Chart.js

## اجرای سریع

فایل `index.html` را در مرورگر باز کنید. نیازی به نصب یا سرور نیست.

## صفحات

| فایل | صفحه |
|------|------|
| `index.html` | داشبورد |
| `orders.html` | سفارش‌ها |
| `products.html` | محصولات |
| `customers.html` | مشتریان |
| `analytics.html` | تحلیل‌ها |

## توسعه (اختیاری)

اگر می‌خواهید استایل‌ها را تغییر دهید:

```bash
npm install
npm run watch
```

برای بیلد نهایی CSS:

```bash
npm run build
```

فایل خروجی: `assets/css/main.css`
